# Rule-Based Chatbot 🤖

## 📌 Project Description
This project is a simple Rule-Based Chatbot developed using Python.
The chatbot responds to user messages using predefined rules and if-else conditions.

## 🚀 Features
- Responds to greetings
- Answers basic questions
- Shows date and time
- Tells jokes
- Continuous conversation until user exits

## 🛠️ Technologies Used
- Python
- VS Code

## ▶️ How to Run
1. Install Python
2. Open chatbot.py file
3. Run the program
4. Start chatting with the bot

## 💬 Example Commands
- hello
- how are you
- time 
- date
- joke
- bye
